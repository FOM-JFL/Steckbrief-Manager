# Steckbrief Manager V7

**Start:**
- Doppelklick auf `start.bat` (öffnet lokalen Server auf Port 8080)
- Im Browser auf http://localhost:8080 gehen

**Inhalt:**
- index.html: Haupt-App
- steckbriefe.json: Daten
- import_steckbriefe.py: Word/JSON Import
- fom-logo.png: Logo
- VERSION: Versionsdatei

**Hinweis:**
- Python muss installiert sein (mind. Version 3)
- Keine weiteren Abhängigkeiten nötig
